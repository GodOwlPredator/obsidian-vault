# 📚 Библиотека — Инструкция

## Структура папок

```
Библиотека 📚/
├── 📖 Все книги.md          ← главный дашборд с сеткой обложек
├── Книги/                   ← файлы книг
└── Инструкция.md            ← этот файл
```

- Папки `Шаблон книги` и `Обложки/` **нет** — шаблон-карточка живёт прямо в `📖 Все книги.md` (кнопка «➕ Добавить книгу»), обложки храни в `Cache/` рядом с книгами и ссылайся на файл по имени.

---

## Быстрый старт

1. Открой **📖 Все книги.md** — главный дашборд с сеткой
2. Добавляй книги кнопкой в дашборде или создавая файл руками

## Как добавить книгу вручную

Создай файл в папке `Книги/` и заполни frontmatter:

```yaml
log: книга                 ← ОБЯЗАТЕЛЬНО, иначе книга не попадёт в дашборд
title: "Atomic Habits"
author: "James Clear"
cover: "Cache/atomic.jpg"  # или "[[название.jpg]]"
genre: "Саморазвитие"
pages: 320
pages_read: 150
status: "читаю"
rating: 0
date_started: 2026-01-10
date_finished:
```

Дашборд ищет книги по полю `log: книга` (не по папке) — файл можно держать в любом месте vault.

---

## Поля в frontmatter

| Поле            | Что означает                      | Пример             |
| --------------- | --------------------------------- | ------------------ |
| `log`           | Тип карточки: всегда `книга`      | `"книга"`          |
| `title`         | Название книги                    | `"Atomic Habits"`  |
| `author`        | Автор                             | `"James Clear"`    |
| `cover`         | Путь к обложке                    | `"Cache/ah.jpg"`   |
| `genre`         | Жанр / тема                       | `"Саморазвитие"`   |
| `pages`         | Всего страниц                     | `320`              |
| `pages_read`    | Прочитано страниц (для прогресса) | `150`              |
| `status`        | Статус чтения                     | `читаю`            |
| `rating`        | Оценка 1–5 (кликай по звёздам)    | `5`                |
| `date_started`  | Дата начала                       | `2026-01-10`       |
| `date_finished` | Дата окончания                    | `2026-02-01`       |

## Статусы

| Значение    | Что означает  | Цвет    |
| ----------- | ------------- | ------- |
| `хочу`      | Хочу прочесть | Жёлтый  |
| `читаю`     | Читаю сейчас  | Красный |
| `прочитано` | Прочитано     | Зелёный |
| `брошено`   | Брошено       | Серый   |

---

## Обложки

1. Найди изображение и положи файл в `Cache/` (или рядом с книгой)
2. Укажи в frontmatter: `cover: "Cache/название.jpg"` или через вики-ссылку `cover: "[[название.jpg]]"`
3. Рекомендуемый размер 300×450px — сетка обложек без обрезаний
