# 🧊 3D Вики — Инструкция

## Что это

Личная вики 3D-художника: идеи, фишки, инструменты, референсы, проекты, материалы,
ассеты, обучение, челленджи и чеклисты. Всё связано между собой через **проекты**
и собрано в **пайплайн производства**.

Открой **🏠 Главная.md** — это хаб со всеми записями.

## Быстрый старт

1. Открой **🏠 Главная.md**.
2. Вверху нажми нужную кнопку: **＋ Идея**, **＋ Фишка**, **＋ Инструмент**,
   **＋ Референс**, **＋ Проект**, **＋ Материал**, **＋ Ассет**, **＋ Обучение**,
   **＋ Челлендж** или **＋ Чеклист**.
3. Введи название (можно сразу описание, теги и проект) → **Создать**.
   Заметка создаётся из шаблона, поле `log` подставляется автоматически,
   метка `шаблон` снимается, файл сразу открывается.
4. Переходы справа: **🖼 Галерея работ**, **🧭 Пайплайн**, **⚙️ Центр**, **📘 Инструкция**.

> Все шаблоны помечены полем `шаблон: true` и содержат `log`. Благодаря метке
> они не попадают в статистику и списки. Создавать записи лучше кнопками —
> тогда метка снимается сама.

## Проекты — как связать всё вместе

**Проект** — главная сущность вики. Он собирает вокруг себя идеи, референсы,
материалы, фишки, обучение и челленджи.

1. Создай проект кнопкой **＋ Проект**.
2. В любой другой записи укажи поле `проект: «Название проекта»`
   (можно прямо при создании — в модалке есть строка «Проект»).
3. Открой карточку проекта — внизу появятся **связанные записи** и **граф связей**
   (проект в центре, записи вокруг, цвет = тип). Клик по узлу открывает запись.

## Карточка записи

У каждой записи внутри — единая карточка (стиль общий для всей зоны):

- **Статус** — кликабельные кнопки (новая / в работе / готово…).
- **Оценка** — звёзды 1–5 (кликом).
- **Прогресс** — у обучения и чеклистов (клик по полосе задаёт процент).
- **Обложка** — картинка из поля `обложка` (или `превью`) наверху, клик — на весь экран.
- **Навигация** — кнопки «← 3D Вики» и «🖼 Галерея».

## Поиск и фильтры на главной

- **Поиск** — по названию и описанию.
- **Сортировка** — сначала новые / старые / по алфавиту / по типу.
- **Чипы типов** — фильтр по одному или нескольким типам.
- **Чипы тегов** — фильтр по тегам (топ-14 по частоте).
- **Обложки** — если у записи задано `обложка`/`превью`, карточка показывает картинку.
