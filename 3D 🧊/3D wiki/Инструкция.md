# 🧊 3D Вики — Инструкция

## Структура папок

```
3D 🧊/3D wiki/
├── 🏠 Главная.md            ← главный дашборд с поиском и фильтрами
├── Идеи/                    ← идеи проектов
│   └── 💡 Идея.md           ← шаблон-карточка
├── Фишки/                   ← техники, приёмы, шорткаты
│   └── 📝 Шаблон фишки.md   ← шаблон
├── Инструменты/             ← программы, плагины, аддоны
│   └── 🔧 Инструмент.md     ← шаблон
├── Референсы/               ← вдохновение, мудборды
│   └── 🎯 Референс.md       ← шаблон-карточка (переименуй)
└── Инструкция.md            ← этот файл
```

---

## Быстрый старт

1. Открой **🏠 Главная.md** — это твой хаб со всеми заметками
2. Чтобы добавить заметку:
   - Скопируй нужный шаблон в соответствующую папку
   - Переименуй по названию
   - Заполни frontmatter и **убедись, что в нём есть поле `log`** — по нему главная находит и группирует записи

---

## Типы записей (поле `log`)

| Значение      | Тип        | Для чего                            |
|---------------|------------|-------------------------------------|
| `идея`        | 💡 Идея    | Идеи для проектов, сцен, концепты   |
| `фишка`       | ⚡ Фишка   | Техники, приёмы, шорткаты, трюки    |
| `инструмент`  | 🔧 Инструмент | Программы, плагины, аддоны        |
| `референс`    | 🖼 Референс | Изображения, стили, вдохновение     |

---

## Требования

- Плагин **Dataview** → включить **Enable DataviewJS**

---

## Советы

- Открой **🏠 Главная.md** закреплённой вкладкой
- Используй поле `теги` для гибкой фильтрации (например: `["lighting", "моделирование", "textures"]`)
- Поле `программы` в идеях принимает список: `["Blender", "Substance"]`
