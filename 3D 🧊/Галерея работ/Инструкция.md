# 🖼 Галерея работ — Инструкция

## Структура папок

```
3D 🧊/Галерея работ/
├── 🖼 Все работы.md        ← галерея: добавление, статистика, прогресс, сетка
├── 💼 Работы/              ← сюда сохраняй файлы каждой работы
│   ├── 1 Работа.md         ← шаблон (помечен «шаблон: true», в галерею не попадает)
│   ├── Проект 1.md
│   └── Проект 2.md
├── Cache/                  ← сюда клади превью и рендеры
└── Инструкция.md           ← этот файл
```

---

## Быстрый старт

1. Открой **🖼 Все работы.md**.
2. Нажми **＋ Новая работа** — заполни название, описание, категорию, год,
   программы и теги. Карточка создаётся из шаблона, метка `шаблон` снимается,
   файл сразу открывается.
3. Переходы справа: **🧊 3D Вики**, **🧭 Пайплайн**, **⚙️ Центр**.

---

## Что есть на странице галереи

- **Статистика:** всего работ, топовых ★4+, средняя оценка, лет работы, программ.
- **Прогресс портфолио:** диаграммы «работы по годам» и «работы по категориям».
- **Избранные работы** — блок сверху (поле `избранное: true`).
- **Поиск**, фильтры по категории и году, сортировка: дата / оценка / алфавит.
- **Сетка работ** с обложками, рейтингом и тегами.

---

## Просмотр работ

- Клик по карточке — открыть заметку работы.
- Клик по **превью** — открыть картинку на весь экран (лайтбокс). Закрыть: клик или `Esc`.

---

## Поля в frontmatter

| Поле           | Что означает                        | Пример                      |
|----------------|-------------------------------------|-----------------------------|
| `log`          | Тип карточки: всегда `работа`       | `"работа"`                  |
| `шаблон`       | Служебная метка шаблона             | у шаблона `true`, у работ нет|
| `title`        | Название работы                     | `"Sci-fi Room"`             |
| `описание`     | Краткое описание                    | `"Интерьер в стиле киберпанк"` |
| `превью`       | Путь к изображению (обложка)        | `"Cache/scifi.jpg"`         |
| `категория`    | Жанр / тип работы                   | `"3D"`, `"Концепт"`, `"UI"` |
| `программы`    | Список программ                     | `["Blender", "Substance"]`  |
| `год`          | Год создания                        | `2026`                      |
| `рейтинг`      | Самооценка 1–5 (кликай по звёздам) | `5`                         |
| `избранное`    | Показывать в блоке избранных        | `true`                      |
| `теги`         | Теги для фильтрации                 | `["lighting", "hard-surface"]` |
| `время_работы` | Сколько времени заняло              | `"2 недели"`                |
| `ссылка`       | Ссылка на ArtStation / Behance      | `"https://..."`             |
| `проект`       | Связь с проектом 3D-вики            | `"Человек под дождём"`      |

## Как добавить превью

1. Сохрани рендер в `Cache/` (рекомендуется квадратное, от 600×600px)
2. В frontmatter укажи путь:

```yaml
превью: "Cache/название.jpg"
```

Или через вики-ссылку:

```yaml
превью: "[[название.jpg]]"
```

---

## Требования

- Плагин **Dataview** → включить **Enable DataviewJS**.
- Сниппет **3d** в «Настройки → Внешний вид → CSS-сниппеты».

## Советы

- Отметь лучшие работы `избранное: true` — они появятся в шапке галереи.
- Указывай `проект`, чтобы работа подтянулась в карточку проекта в вики.
- Открой **🖼 Все работы.md** закреплённой вкладкой.
