# 🇬🇧 Английский

лексика, 5 слов в день, тренировка в обе стороны

## 📚 Программа и материалы

- [[Учёба 🎓/Английский — слова|Слова и тренировка]] — таблица слов с автопереводом
- [[Учёба 🎓/Инструкция|Инструкция по учёбе]]

## 🧠 Как устроено / что важно

- Слово вписываю сам, перевод подставляет кнопка «Перевести пустые» (Google, запасной MyMemory).
- Служебные колонки («Добавлено», «Уровень», «Следующий повтор») заполняются сами, руками не трогаю.
- Интервалы: 1 → 1 день, 2 → 3, 3 → 7, 4 → 14, 5 → 30. «Не знал» сбрасывает на 1.
- Тренировка спрашивает в обе стороны (EN → RU и RU → EN), ответ вводится с клавиатуры. Опечатка в одну букву прощается.

## 📌 Дедлайны и примечания

- Нормы в день нет по времени — только 5 новых слов, когда удобно.
- **Murphy Essential Grammar in Use 4th ed. (with answers) заказан 26.10.2026** — нужен к 16.11, начало этапа 1. Пока едет — этап 0 (чтение), книга не нужна.

## 🎯 Цель (с 26.10.2026)

Старт — **абсолютный ноль** (A0): алфавит не знаю, читать не умею, считать до 100 не могу, на слух не пишу и т.д.

Цель на 5 месяцев — уверенный **A2 / начало B1**: говорить о себе и бытовых темах, понимать медленную речь, читать адаптированные книги, писать базовые фразы без грубых ошибок. «Свободно с носителем» и «читать книги в оригинале» — это B2-C1, следующий блок

Английский идёт **фоном 15 минут в день**, основное направление — физика.

## 📎 Транскрипция — запланирована, этап 2

Не «когда встретится», а отдельным уроком на этапе 2 (примерно декабрь 2026). Один раз, 20 минут, 15 значков — и всё.

До этапа 2: значкú в словарях **пропускать глазами**, произношение брать из озвучки Google Translate.

## ⚖️ Правила «не в кашу» (важнее самого плана)

1. **Один учебник** — *Murphy*
2. **Одна книга за раз.** Дочитал, выписал всё нужное и запомнил — следующая.
3. **Новое только после проверки этапа.** В следующий этап не заглядываю.
4. **Сорвался на неделю — возвращаюсь на текущий юнит**, а не начинаю сначала. Это и отличает от прошлых попыток.

## ⏱ Мой день (15 минут)

- 10 мин — 1 юнит Murphy (правило + упражнения)
- 5 мин — слова (Anki или тренажёр в vault)
- в «хороший день» +15 мин — чтение вслух или Bookworms

Чтение и слух — добавка, не ежедневная обязанность.

## 🚫 Чего не надо делать

- **Duolingo как основа** — учит узнавать, а не говорить.
- **Сериалы без субтитров** на A0 — это шум.
- **«1000 слов за неделю»** — без повторений уходят.
- **Курсы «до C1 за год»** — врут.

## 🎙 Самый честный замер

Диктофон. Запись месяца 0 против записи месяца 3 — одна и та же фраза «My name is… I study…». Разницу слышно ушами, это и есть доказательство прогресса.

async function setValue(path, key, val) {
    const tf = app.vault.getAbstractFileByPath(path);
    if (!tf) return;
    let content = await app.vault.read(tf);
    const re = new RegExp("^(" + key + ":\\s*).*$", "m");
    content = re.test(content)
        ? content.replace(re, "$1" + val)
        : content.replace(/^---\n/, "---\n" + key + ": " + val + "\n");
    await app.vault.modify(tf, content);
}

function uniquePath(folder, base) {

async function createFrom(tpl, tokens, folder, base) {
    const t = app.vault.getAbstractFileByPath(tpl);
