# Инструкция по английскому инструментарию

Кратко и по делу. Всё работает через ваши инструменты.

## 1) Горячие клавиши (Hyprland)
| Клавиша | Действие |
|---|---|
| `SUPER+SHIFT+T` | Перевести **выделенный** текст в любом окне |
| `SUPER+SHIFT+A` | Окно перевода `en-tr` |
| `SUPER+SHIFT+R` | Повторение Anki в терминале |
| `SUPER+SHIFT+E` | **Английское меню** `en-menu` (всё в одном месте) |

## 2) Окно перевода `en-tr`
1. Нажать `SUPER+SHIFT+A` или `SUPER+SHIFT+T`
2. Вставить/написать текст — перевод появится автоматически по `Ctrl+Enter` или кнопке `Перевести`
3. Кнопка `＋ В Anki` — добавить слово/фразу в нужную колоду
4. Кнопка `Из выделения` — взять текст из выделения
5. Кнопка `Инбокс` — открыть заметку инбокса в Obsidian

## 3) Закладка «Перевод» в браузере
**Установка:**
1. Открыть `~/install-en.html` (или `xdg-open ~/install-en.html`)
2. Показать панель закладок `Ctrl+Shift+B`
3. **Перетащить** синюю кнопку `🌐 Перевод` на панель закладок

**Использование:**
1. Открыть англоязычную страницу → нажать `🌐 Перевод` на панели
2. Под абзацами появится перевод
3. Кликнуть по **любому слову** — всплывающее окошко с переводом
4. **Выделить** предложение/фразу мышью и отпустить — переведёт выделенное целиком
5. Нажать `＋ В Anki` во всплывашке — добавит в Anki (через `anki://`)
6. Повторный клик по закладке или `Esc` — выключить

*Если сайт совсем не даёт перевести (редко)* — выделите текст и нажмите `SUPER+SHIFT+T`.

## 4) Инбокс Obsidian → Anki
**Файл:** `Учёба 🎓/Предметы/📥 Добавление новых слов.md`

Пишите так:
```text
- capacitor = конденсатор
- the board does not work = плата не работает | The board does not work at all.
```

- Одно-два слова → карточка-слово (EN↔RU)
- Фраза из 3+ слов → разговорная карточка
- Можно использовать `—` вместо `=`

После сохранения файла:
- Строка автоматически **переезжает** в раздел `## Уже в Anki` с датой `✓ DD.MM.YYYY`
- Слово сразу появится в Anki, если он **закрыт**
- Если Anki **открыт** — уйдёт в очередь и добавится после закрытия
- Список всех слов обновляется в `📚 Мои слова.md`

## 5) Видео с русскими/английскими субтитрами
**Запуск:**
```bash
en-video /путь/к/файлу.mp4
en-video https://youtube.com/...
```

**Клавиши в mpv:**
| Клавиша | Действие |
|---|---|
| `v` | Вкл/выкл субтитры |
| `j` / `J` | Переключить между EN/RU дорожками |
| `b` | Режим «оба» (удобно для сравнения) |
| `1` | Только **русские** |
| `2` | Только **английские** |
| `t` | Открыть перевод **текущей строки** в окне `en-tr` |
| `c` | **Скопировать** английскую строку в буфер обмена |
| `a` | Добавить текущую строку в **инбокс Obsidian** (потом улетит в Anki) |

Совет: `1` — когда просто смотришь с переводом. `2` — когда хочешь привыкать к английскому. `b` — когда хочется сверить конкретное предложение.

## 6) Английское меню
Нажми `SUPER+SHIFT+E` — меню со всем сразу: перевод, инбокс, слова, повторение, видео, установка закладки, инструкция.

## Быстрая проверка связки
1. Выделить слово → `SUPER+SHIFT+T` ✓
2. Страница в браузере → закладка `🌐 Перевод` → клик по слову → `＋ В Anki` ✓
3. `📥 Добавление новых слов.md` → дописать строку → сохранить → строка уедет в «Уже в Anki» ✓
4. `en-video` + `a`/`t`/`c` в mpv ✓
