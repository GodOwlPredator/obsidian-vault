# 🎓 Учёба — Инструкция

Раздел подстроен под специальность: **«Ремонт, монтаж и обслуживание электрического и электромеханического оборудования (по отраслям)»**, УРТК.

## Структура

```
Учёба 🎓/
├── 📊 Дашборд.md              ← вход: профиль, предметы, дедлайны, свежие конспекты
├── 📅 Расписание.md           ← расписание недели, преподавтели
├── Предметы/                  ← карточки предметов (по одному файлу)
│   ├── 📕 Русский язык.md
│   ├── 🧪 Химия.md
│   └── …
├── Конспекты/                 ← заметки по занятиям и лабораторным
│   └── 2026-10-08 Химия.md
├── Задания/
│   └── ✅ Трекер заданий.md    ← все ДЗ и дедлайны, добавление в один клик
└── Инструкция.md              ← этот файл
```

Шаблоны лежат в общем `Templates/`:
- `Templates/📋 Шаблон предмета.md`
- `Templates/📝 Шаблон конспекта.md`
- `Templates/📝 Шаблон задания.md`

---

## Быстрый старт

1. Открой **📊 Дашборд.md** — это главный экран.
2. Новый предмет: скопируй `Templates/📋 Шаблон предмета.md` в `Предметы/`, переименуй, заполни `name`.
3. Конспект: открой карточку предмета и жми **「＋ Конспект」** — создастся файл с сегодняшней датой.
4. Задание: в карточке предмета жми **「＋ Задание」**, либо добавь в **✅ Трекере заданий** через форму (там же ставятся статусы).
5. ⚡ Главное: **не удаляй поле `type`** из frontmatter — по нему всё собирается.

> Файлы можно класть в любую папку — дашборд и карточки находят их по полю `type` (и `subject`), а не по расположению.

## Поля предмета (frontmatter)

| Поле      | Описание                | Пример              |
|-----------|-------------------------|---------------------|
| `type`    | Всегда `предмет`        | `предмет`           |
| `name`    | Название (важно!)       | `"Химия"`           |
| `emoji`   | Смайлик предмета        | `"🧪"`              |
| `teacher` | Преподаватель           | `"Иванов И.И."`     |
| `семестр` | Номер семестра          | `1`                 |
| `status`  | `активный` / `завершён` | `активный`          |

## Поля конспекта (frontmatter)

| Поле          | Описание                    | Пример                      |
|---------------|-----------------------------|-----------------------------|
| `type`        | Всегда `конспект`           | `конспект`                  |
| `date`        | Дата занятия (ISO)          | `2026-10-08`                |
| `subject`     | Предмет (точно как в карточке!) | `"Химия"`              |
| `тема`        | Тема занятия                | `"Переменный ток"`         |
| `лабораторная`| `true` если это лабораторная| `false`                    |

## Поля задания (frontmatter)

| Поле      | Описание              | Пример          |
|-----------|-----------------------|-----------------|
| `type`    | Всегда `задание`      | `задание`       |
| `task`    | Название задания      | `"Реферат"`     |
| `subject` | Предмет               | `"Химия"`       |
| `priority`| `высокий/средний/низкий` | `средний`   |
| `status`  | `не начато/в работе/готово` | `в работе` |
| `due`     | Срок сдачи (ISO)      | `2026-10-15`    |

---

## Статусы заданий

- `не начато` — только получил
- `в работе` — делаю
- `готово` — сдано (зачёркивается, зелёная метка)

Просроченные задания (дата `due` меньше сегодняшней, статус не `готово`) подсвечиваются красным в дашборде и трекере.

---

## Требования

- Плагин **Dataview** → **Enable DataviewJS**
- Поле `subject` в конспекте/задании должно совпадать с `name` предмета — иначе связи не работают

---

## Советы

- Держи **📊 Дашборд.md** закреплённой вкладкой (или в ⚙️ Центре управления).
- Конспектам давай формат имени `ГГГГ-ММ-ДД Предмет.md` — сортируются сами.
- Расписание веди в **📅 Расписание.md**: по нему видно, к чему готовиться.
- В карточке предмета держи «как устроено / что важно» — это твой шпаргалок по предмету.
