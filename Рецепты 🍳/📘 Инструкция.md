# 📘 Инструкция — как всё устроено

> [!info] Коротко
> Рецепты — **обычные заметки** в папке `Рецепты 🍳` с полем `type: рецепт`.
> Всё остальное (поиск, карточки, режим готовки, таймеры) рисует движок внутри заметки **`📖 Книга рецептов`**.
> Открываешь книгу → видишь дашборд. Открываешь рецепт → видишь просто текст.
>
> Даже если этот файл потеряется — движок книги никуда не денется, а рецепты читаются как обычный markdown в любой программе.

---

## 1. За 30 секунд: как пользоваться

1. Открой **`Рецепты 🍳/📖 Книга рецептов`** — это и есть весь интерфейс.
2. Нажми **`＋ Новый рецепт`** → заполни название, категорию, порции, время, сложность → **Создать**.
3. Открылся созданный файл — впиши **ингредиенты** и **шаги** в нужные разделы (шаблон уже подставлен).
4. Вернись в книгу (или нажми в карточке **`✏`** = открыть заметку). Карточка рецепта обновится сама при переоткрытии книги.
5. Нажми **`▶ Готовить`** на карточке — откроется полноэкранный пошаговый режим с таймерами.

> [!tip] Если правка не видна
> Dataviewjs не следит за файлами посторонних заметок в реальном времени.
> **Закрой и снова открой** заметку книги (или `Ctrl+R` в Obsidian) — дашборд перерисуется.

---

## 2. Карта файлов (что за что отвечает)

| Что | Путь | Зачем |
|---|---|---|
| **Книга** | `Рецепты 🍳/📖 Книга рецептов.md` | Движок + дашборд. Основной экран. |
| **Рецепты** | `Рецепты 🍳/*.md` | Обычные заметки с `type: рецепт`. |
| **Шаблон** | `Templates/🍳 Шаблон рецепта.md` | С него создаются новые рецепты. Можно править. |
| **Стили** | `.obsidian/snippets/recipes.css` | Внешний вид заметки, книги и оверлея готовки. |
| **Включение сниппета** | Настройки → Внешний вид → CSS-сниппеты → `recipes` | Должен быть включён. |

Как это связано:

- Книга — это заметка с `cssclasses: [recipe-book]` и **одним блоком ```dataviewjs```** (весь код внутри).
- Рецепт — заметка с `cssclasses: [recipe]` и `type: рецепт` в свойствах.
- Сниппет `recipes.css` красит и то, и другое.
- **Подстраховка:** если сниппет выключен, книга при открытии сама подтягивает `recipes.css` из файла и вставляет в страницу (`ensureRecipeCss`). Значит книга будет выглядеть правильно в любом случае, а вот **отдельная заметка-рецепт — только если сниппет включён** (или книга открыта в этой же сессии Obsidian).

## 3. Создание рецепта

### Кнопкой (рекомендую)
`＋ Новый рецепт` в книге → модалка:
- **Название** — обязательно. Из него делается имя файла (запрещённые в путях символы заменяются на пробел).
- **Категория** — свободный текст, с подсказками из уже существующих. Пусто → «Без категории».
- **Порций** — базовое число порций (по умолчанию 2).
- **Время, мин** — общее время.
- **Сложность** — `легко` / `средне` / `сложно`.

Enter создаёт рецепт, Esc — отмена. Готовый файл создаётся из `Templates/🍳 Шаблон рецепта.md` и сразу открывается.

### Вручную
Создай заметку в папке `Рецепты 🍳` и в её **свойствах** укажи хотя бы два поля:

```yaml
type: рецепт
title: "Название"
```

Если `type: рецепт` не указать — заметка **не попадёт в книгу**. Если не указать `title` — возьмётся имя файла.

## 4. Свойства (frontmatter) рецепта

Все поля кроме `type` — необязательные:

| Поле | Что делает | Пример |
|---|---|---|
| `type` | **Обязательно** = `рецепт`. По нему книга находит рецепты. | `рецепт` |
| `cssclasses` | Красит заметку-рецепт. Ставится из шаблона. | `- recipe` |
| `title` | Название в карточке и в режиме готовки. | `Паста карбонара` |
| `category` | Категория-чип и фильтр в книге. | `Основное` |
| `servings` | Базовое число порций → пересчёт в готовке. | `2` |
| `time` | Время, мин. Используется сортировкой «Быстрые». | `30` |
| `difficulty` | `легко` / `средне` / `сложно`. | `средне` |
| `emoji` | Иконка блюда. Пусто → автоподбор (см. §9). | `🍝` |
| `kcal` | Калорийность (просто показывается). | `450` |
| `cuisine` | Кухня (в резерве). | `итальянская` |
| `tags` | Теги — участвуют в поиске. | `- ужин` |

> [!note] Числа
> `servings`, `time`, `kcal` удобно держать строками в кавычках, как в шаблоне («40», а не 40) — книга одинаково понимает и так, и так.

## 5. Тело рецепта

Движок читает **два раздела по заголовкам**:

```markdown
## 🧺 Ингредиенты
- Название — 100 г
- Название — 2 шт
- Соль, перец — по вкусу

## 👨‍🍳 Приготовление
1. Текст первого шага.
2. Шаг с таймером. ⏱5
3. Ещё шаг. ⏱10
```

Правила распознавания заголовков:

- Раздел ингредиентов — заголовок, содержащий слово **«ингредиент»**.
- Раздел шагов — заголовок, содержащий **«приготовл», «инструкц», «процесс» или «шаг»**.
- Любой другой заголовок **закрывает** раздел (текст «## 📝 Заметки» уже не считается ни ингредиентами, ни шагами).

Всё остальное (заголовок `# 🍳 Название`, блок «> [!info] Кратко», раздел «Заметки») книга **не трогает** — это для чтения глазами.

### Форматирование текста

В названиях ингредиентов и в шагах работает базовое оформление — оно отображается и в книге, и в режиме готовки:

| Пишешь | Получаешь |
|---|---|
| `**жирный**` или `__жирный__` | **жирный** |
| `*курсив*` или `_курсив_` | *курсив* |
| `` `код` `` | `код` |
| `~~зачёркнуто~~` | ~~зачёркнуто~~ |
| `"текст"` | «текст» |
| `...` | … |

Пример строки шага: `1. Обжарить **мясо** до *золотистого* цвета. ⏱10`
Пример ингредиента: `- **Мука** — 200 г`

## 6. Ингредиенты: как записывать

Формат строки: `- Название — количество`

- **Разделитель** — длинное тире `—` или среднее `–` (любое из них). Пробелы вокруг не важны.
- **Слева** — название.
- **Справа** — количество.

Что понимает количество:

| Запись | Результат |
|---|---|
| `100 г` | число 100, единица «г» |
| `1,5 л` | 1.5, единица «л» |
| `1/2 ст. л.` | 0.5, единица «ст. л.» |
| `2 шт` | 2, единица «шт» |
| `по вкусу` | без числа — выводится как есть |
| `соль, перец` (без тире) | вся строка = название, количества нет |

Важно:

- **Единица — это всё, что идёт после числа** (`1/2 ст. л.` → единица `ст. л.`).
- Дробь `1/2` считается как 0.5; десятичная через **запятую** `1,5`.
- Количество **умножается** при смене порций в режиме готовки (см. §7).
- Любые строки со `-`, `*` или `+` в начале считаются ингредиентами: `- Соль — 1 щепотка`.
- **Длинные названия и количества переносятся на новую строку** — ничего не обрезается. В широком (полноэкранном) окне левая панель становится шире, и переносов меньше.

> [!tip] Сколько ингредиентов/шагов
> Нет жёсткого лимита. Пара десятков строк работают нормально, список в готовке прокручивается.

## 7. Шаги и таймеры

Шаг — строка, начинающаяся с числа (`1.`, `2)`) или маркера (`-`, `*`, `+`).

### Метка таймера `⏱`
В **конец** строки шага дописываешь `⏱` + время:

| Написано | Таймер |
|---|---|
| `⏱5` | 5 минут |
| `⏱1,5` | 1 минута 30 секунд |
| `⏱2ч` | 2 часа |
| `⏱90` | 90 минут (= 1:30:00) |

Метка из текста шага убирается — на экране остаётся чистый текст, а рядом кнопка запуска.

### Как ведут себя таймеры в готовке
- **Запуск:** кнопка `▶ Таймер 5:00` под шагом (если у шага есть `⏱`), либо **быстрые таймеры** `1 / 3 / 5 / 10 мин`, либо кнопка `⏱ 5:00` у шага в списке «☰ Все шаги».
- **Одновременно** можно держать **сколько угодно** таймеров — они собираются в панели справа сверху.
- **У каждого таймера:** `⏸/▶` пауза-продолжить, `+1м` добавить минуту, `✕` удалить.
- **Когда время вышло:** три звуковых сигнала, вспышка экрана, всплывашка «⏰ время вышло», время становится зелёным.
- **Сработавший таймер:** кнопка `↺` — запустить **заново на полное** время (не с нуля).
- **Живут только пока открыт оверлей готовки.** Закрыл готовку — таймеры обнулились. Это осознанно: таймер относится к текущей готовке.

> [!warning] Звук не сработал?
> Браузер/Electron может блокировать звук, если аудио не было «разбужено» действием пользователя.
> Книга делает это сама: при нажатии на любой таймер контекст звука создаётся/разблокируется (`primeAudio`). Достаточно, чтобы ты запускал таймер **кликом**, а не программно.

## 8. Режим готовки (оверлей)

Открывается кнопкой **`▶ Готовить`** на карточке или **`🎲`** (случайный рецепт сразу в готовку).

Что на экране:

- **Сверху:** эмодзи + название, счётчик порций `− N +`, `☰ Все шаги`, `⛶` полный экран, `✕` закрыть.
- **Слева:** список ингредиентов с **чекбоксами** (отмечаешь, что уже положил) и пересчётом количеств под выбранное число порций. Если порции ≠ базовые, появляется множитель «(×N)».
- **Центр:** текущий шаг крупным текстом, «Шаг N из M», кнопки таймера.
- **Низ:** `◀ Назад` / `Далее ▶`, точки-шаги (клик — прыжок на шаг).
- **Справа сверху:** плавающая панель таймеров.

Закладки/настройки:

- **Полный экран** открывается сразу при входе в готовку (если браузер разрешает).
- **Wake lock** — пока готовишь, экран не гаснет.
- Порции меняются от 1 до 50.

### Клавиши

| Клавиша | Действие |
|---|---|
| `Esc` | Закрыть готовку (в полном экране — сначала выйти из него) |
| `→` / `PageDown` / `Пробел` | Следующий шаг |
| `←` / `PageUp` | Предыдущий шаг |
| `F` (или `А`) | Переключить полный экран |

> [!note] Пробел и кнопки
> Если фокус стоит на кнопке/поле — пробел «нажимает» её, а не листает шаг. Так задумано.

- Последний шаг, кнопка **`Готово ✓`** → закрывает готовку и желает приятного аппетита.
- **`☰ Все шаги`** — весь рецепт списком; клик по шагу открывает его в обычном виде.

## 9. Иконка (эмодзи) блюда

Порядок выбора: **поле `emoji` → автоподбор → `🍽️`**.

- **Хочешь конкретную** — впиши её в свойствах: `emoji: 🍜`.
- **Хочешь автоподбор** — оставь поле пустым.

Автоподбор смотрит на **категорию + название**, первое совпадение:

| Ключевые слова | Эмодзи |
|---|---|
| паст, макарон, спагет, лапш | 🍝 |
| суп, борщ, бульон, похлёб | 🍲 |
| салат | 🥗 |
| завтрак, омлет, яичн, каш, сырник, блин | 🍳 |
| выпеч, хлеб, пирог, печень, кекс, тест(о/а) | 🥐 |
| десерт, сладк, торт, пирожн, морожен | 🍰 |
| напит, кофе, чай, смузи, компот, коктейл | 🥤 |
| соус, заправк, приправ, специ | 🧂 |
| мясо, говяд, свинин, стейк, котлет, шашлык | 🥩 |
| куриц, кури, птиц, индейк | 🍗 |
| рыб, морепрод, кревет, лосос | 🐟 |
| гарнир, овощ, картоф, рис, греч | 🥔 |

Если ничего не подошло — 🍽️.

## 10. Дашборд-книга: поиск, фильтры, сортировка

- **Поиск** — ищет по названию, категории, тегам и **названиям ингредиентов**. Несколько слов = все должны встретиться.
- **Чипы категорий** — клик фильтрует по категории, «Все» — сброс.
- **Сортировка:**
  - `Сначала А–Я` — по названию;
  - `Быстрые` — по времени приготовления (сначала меньшие);
  - `Новые` — по времени последнего изменения файла.
- **Карточка:** эмодзи, название, категория, время, порции, сложность, ккал, число шагов + кнопки:
  - **`▶ Готовить`** — открыть режим готовки;
  - **`✏`** — открыть заметку-рецепт (наведи — увидишь подсказку);
  - **`🗑`** — удалить рецепт (с подтверждением; уходит в корзину — `Настройки → Файлы и ссылки → Корзина`, если она настроена, иначе удаляется);
  - клик по самой карточке — тоже открыть заметку.
- **`🎲`** — случайный рецепт сразу в режиме готовки.

## 11. Если что-то не так

| Симптом | Что делать |
|---|---|
| Книга пустая / «Пока пусто» | У рецептов нет `type: рецепт` в свойствах. Проверь §4. |
| Не видно нового рецепта | Переоткрой заметку книги (`Ctrl+R`). Dataviewjs не обновляется сам. |
| Вид «поехал», нет стилей | Включи сниппет: Настройки → Внешний вид → CSS-сниппеты → `recipes`. |
| Книга как обычный текст с ошибкой | Проверь, что плагин **Dataview** включён и в нём разрешены **JS-запросы** (Settings → Dataview → Enable JavaScript Queries). |
| Таймер без звука | Запускай таймер **кликом**, не программно; проверь системный звук. |
| Рецепт-заготовка попал в книгу как «{{TITLE}}» | Это шаблон. Он в `Templates/` и отфильтрован; если скопировал шаблон в папку рецептов — заполни поля, и `{{ }}` уйдут. |
| Добавил рецепт вручную, не видно | Нужны минимум `type: рецепт`; переоткрой книгу. |
| Хочу другой вид карточек | Правь `.obsidian/snippets/recipes.css`. Логику — в блоке ```dataviewjs``` книги. |

## 12. Технические детали (для правок)

- Весь движок — **один блок** ```dataviewjs``` в заметке книги: парсинг рецептов, дашборд, оверлей готовки, создание/удаление.
- Ключевые места в коде: `parseRecipe` (разбор тела), `loadRecipes` (сбор и фильтр заметок), `catEmoji` (иконки), `openCook` (оверлей), `startTimer`/`tick`/`renderTimers` (таймеры), `newRecipeModal` (создание), `card`/`draw` (карточки и фильтры), `renderIngredients` (пересчёт порций).
- Стили — `.obsidian/snippets/recipes.css`. Классы: `.rb-*` (книга/карточки), `.rc-*` (заметка-рецепт и оверлей готовки). Критичные стили оверлея продублированы инлайном в JS — оверлей работает даже без сниппета.
- Рецепты **переносятся как обычные .md**. Стили и код живут в `.obsidian` и в заметке книги — при переносе vault'а переезжают вместе с ним.
- Правки движка: после изменений в блоке ```dataviewjs``` прогонять проверку синтаксиса и тесты (см. `AGENTS.md`, раздел «книга рецептов» — там же перечислены грабли, чтобы не наступить дважды).

## 13. Связанное

- **Центр управления** (`⚙️ Центр управления`) → секция «📂 Дашборды» → карточка «🍳 Рецепты».
- Бэкап: кнопка «Залить в облако» в Центре управления кладёт весь vault (включая рецепты и эту инструкцию) в приватный репозиторий.
