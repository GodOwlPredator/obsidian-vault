# 📝 Задачи — Инструкция

Раздел-«пункт сбора»: сюда сами стекаются все неотмеченные задачи (`- [ ]`) из всех заметок vault. Ничего настраивать не нужно — достаточно просто ставить галочки в том файле, где ты сейчас, а смотреть всё в одном месте здесь.

## Структура

```
Задачи/
├── 📝Задачи.md    ← единый список всех задач
└── Инструкция.md  ← этот файл
```

## Как всё работает

1. **Откуда берутся задачи.** Любая строка `- [ ] текст` в любой заметке (дневник, планы, учёба, обычная заметка) автоматически появляется здесь. Отметил `[x]` — задача уходит в «Выполненные». Подзадачи (вложенные `- [ ]` внутри другой задачи) не показываются — чтобы не шуметь.

2. **Группы = папки vault.** Задачи сгруппированы по месту жизни, чем больше активных задач в папке — тем выше её группа:
   - **📥 Быстрый захват** — «Задачи/» — задачи, добавленные прямо отсюда через поле «＋ Добавить»;
   - **📓 Дневник и мысли** — папка «Заметки/» — это твои ежедневные заметки (`31-май-2026.md` и т.п.), куда ты пишешь мысли, что сделал и что планируешь. Задачи, раскиданные по дням, — самые частые, поэтому группа обычно сверху;
   - **🎓 Учёба, 🗺 Планы на будущее, 📚 Книги, 🧊 3D, 🏋️ Спорт** и другие — соответствующие папки;
   - остальное группируется по имени папки (у подписи группы всегда написано её реальное имя).
   Клик по группе не нужен — просто листай.

3. **Что означает каждая деталь задачи:**
   - **Квадратик слева** — галочка. Клик = выполнено, ещё клик = вернуть. Запись `[x]` пишется прямо в ту заметку, где лежит задача;
   - **Цветная точка** — приоритет. **Клик по точке меняет приоритет** (по кругу: красный → оранжевый → жёлтый → зелёный → серый). Приоритет сохраняется в файл тегом `#критично` / `#высокий` / `#средний` / `#низкий` / `#когда-нибудь`;
   - **Текст задачи** — клик открывает заметку, где задача лежит;
   - **Серые метки** вида `#важно` — твои теги из строки задачи (теги-приоритеты не показываются);
   - **Справа серым** — где записана задача (файл). Для дневника вместо имени файла показывается дата: `📅 31.05`.

4. **Поиск** (верхнее поле) — мгновенно фильтрует по тексту, тегу, файлу и папке. Удобно, когда «я же где-то это писал…».

5. **Фильтры-чипы:** «Все» / любая папка — показать только её; «○/✓ Выполненные» — показать/скрыть выполненные.

6. **Добавить** — пишешь текст, **выбираешь приоритет** из выпадающего списка и жмёшь Enter (или «＋ Добавить»). Задача сохраняется в этой заметке с выбранным приоритетом (в файл пишется тег `#приоритет`) и попадает в группу «📥 Быстрый захват». Приоритет легко поменять потом — клик по точке.

## Цвета приоритетов

| Точка | Приоритет | Тег в файле | Когда так отмечать |
| --- | --- | --- | --- |
| 🔴 красная | критично | `#критично` | горит, дедлайн сегодня |
| 🟠 оранжевая | высокий | `#высокий` | важно, сделать в ближайшие дни |
| 🟡 жёлтая | средний | `#средний` | обычная задача (по умолчанию) |
| 🟢 зелёная | низкий | `#низкий` | не срочно |
| ⚪ серая | когда-нибудь | `#когда-нибудь` | мечты, идеи, потом |

Внутри группы задачи отсортированы по приоритету (сначала критичное).

## Требования

- Плагин **Dataview** → **Enable DataviewJS**.

## Советы

- Не переезжай задачи вручную — просто пиши `- [ ]` там, где мысль пришла, а здесь они сами соберутся.
- Хочешь быстро записать задачу посреди дня — открой 📝Задачи и впиши в поле «Добавить».
- Раз в день (в дневнике) пробеги взглядом по верху списка: критичное закрыто — день удался.
