## 1. Что умеет виджет

| Функция | Описание |
|---|---|
| 🎙 Запись голоса | Через микрофон, сохраняет `.webm` в выбранную папку хранилища |
| 📊 Живая волна | Реальная визуализация звука через Web Audio API |
| 🗣 Транскрипция | Распознавание речи в реальном времени (ru-RU, через Web Speech API) |
| 📎 Вставка ссылки | Автоматически вставляет `![[файл.webm]]` в активную заметку |
| ⌨️ Горячие клавиши | Три независимых хоткея, работают при любой раскладке клавиатуры |
| 🗂 Последние записи | Список 6 последних файлов с воспроизведением и вставкой ссылки |
| 📌 Плавающий | Позиция запоминается, можно перетаскивать за шапку |
| ⚙️ Настройки | Папка сохранения, режим, хоткеи — всё прямо в виджете |

## 2. Требования

### Обязательно

| Плагин | Где взять | Что включить |
|---|---|---|
| **Dataview** | Сообщество плагинов Obsidian | Settings → Dataview → ✅ **Enable JavaScript Queries** |

### Дополнительно (опционально, но рекомендуется)

- **CSS-сниппеты** (встроено в Obsidian) — красиво оформляют аудио-плееры в заметках
- Templater не нужен: виджет запускается при открытии файла рекордера

### Браузерная поддержка

Виджет использует стандартные Web API — работает в Obsidian Desktop (Chromium-движок). На мобильных устройствах запись может не работать из-за ограничений iOS/Android.

## 3. Установка — пошагово

### Шаг 1 — Включить JavaScript в Dataview

```
Obsidian → Настройки (⚙) → Dataview → Enable JavaScript Queries → ВКЛ
```

### Шаг 2 — Скопировать файлы виджета

В хранилище уже находится:
- `Голосовой рекодер 🎙️/Голосовой рекодер 🎙️.md` — сам виджет
- `.obsidian/snippets/voice-notes.css` — оформление аудио-плееров (включено)


### Шаг 3 — Установить CSS-сниппет

1. Скопируй файл `voice-notes.css` в папку `.obsidian/snippets/`  
   *(папка `.obsidian` находится в корне хранилища; если папки `snippets` нет — создай)*
2. В Obsidian: **Настройки → Внешний вид → CSS-сниппеты**
3. Найди `voice-notes` в списке и включи переключатель ✅

### Шаг 4 — Разрешить микрофон

При первом открытии виджета браузер попросит доступ к микрофону.  
Нажми **Разрешить**. Это разовое действие.

> ⚠️ Если доступ уже был отклонён — сбрось разрешения:  
> Obsidian → Help → Show developer tools → Application → Site Settings → Microphone → Allow

## 4. Интерфейс виджета

```
┌─────────────────────────────────┐
│ ● РЕКОРДЕР           ⚙  ↓  ✕   │  ← Шапка (перетаскиваемая)
├─────────────────────────────────┤
│  ▁▂▃▅▃▂▁  (живая волна)         │  ← Canvas-визуализация
│  00:00   [ Начать запись ]      │  ← Таймер + кнопка
└─────────────────────────────────┘
```

**Кнопки шапки:**

| Кнопка | Действие |
|---|---|
| `⚙` | Открыть/закрыть панель настроек |
| `↓` / `↑` | Развернуть / свернуть нижний блок (транскрипция, записи) |
| `✕` | Закрыть виджет |

**Повторно открыть виджет** — просто перейди на вкладку файла `🎙️ Голосовой Рекордер.md`.  
Или назначь горячую клавишу «Показать / Скрыть» (см. раздел 7).

**Перемещение** — тяни виджет за шапку. Позиция сохраняется автоматически в `localStorage`.

## 5. Режимы сохранения

Настраивается в **⚙ → Режим сохранения**.

### Режим 1 — Только сохранить *(по умолчанию)*

- Файл создаётся в папке хранилища
- Ничего не вставляется в заметки
- Подходит когда ты просто фиксируешь мысли «на потом»

### Режим 2 — Сохранить + вставить ссылку

- Файл создаётся в папке хранилища
- В **активную заметку** (последнюю открытую, не сам рекордер) автоматически вставляется `![[Голосовая ДД-ММ-ГГГГ ЧЧ-ММ.webm]]`
- Ссылка встаётся в место курсора
- Подходит когда пишешь заметку и хочешь добавить к ней голосовой комментарий

> Если нужная заметка не открыта — ссылка автоматически скопируется в буфер обмена и появится уведомление.

## 6. Распознавание речи (транскрипция)

Виджет использует **Web Speech API** — это встроенная технология Chromium, работает через интернет-сервис Google (только передача аудио для распознавания, файл сохраняется локально).

**Как это выглядит:**
- Во время записи в развёрнутом блоке (`↓`) появляется текст
- *Курсивный серый* текст — промежуточный результат (ещё обрабатывается)
- Обычный белый текст — финальный результат

**Кнопка «Вставить текст в заметку»** — появляется после записи, если есть финальный текст.  
Нажатие вставляет транскрипцию в активную заметку (или копирует в буфер).

> ⚠️ Транскрипция работает только для **русского языка** (ru-RU).  
> Если нужен другой язык — найди `recog.lang="ru-RU"` в файле виджета и замени код.

## 7. Горячие клавиши

Три независимых хоткея настраиваются в **⚙ → Горячие клавиши**.

| Хоткей | Действие |
|---|---|
| **Старт / Стоп записи** | Начать или остановить запись |
| **Показать / Скрыть** | Открыть или закрыть виджет |
| **Вставить текст / ссылку** | Вставить транскрипцию (если есть) или ссылку на последний файл |

### Как назначить хоткей

1. Открой настройки: нажми `⚙` в шапке виджета
2. Нажми на поле рядом с нужным действием (например, «Старт / Стоп записи»)
3. Поле подсветится красным и покажет «Нажми комбинацию…»
4. Нажми нужную комбинацию — например `Ctrl + R` или `Alt + Q`
5. Комбинация отобразится в поле
6. Нажми **«Сохранить настройки»** в конце

> **Отмена** — нажми `Escape` во время ввода.  
> **Сбросить хоткей** — кликни поле и нажми любую «нейтральную» клавишу, которую не жалко, потом перезапиши нужной.

### Работа при любой раскладке

Хоткеи привязаны к **физической клавише** (не символу). Это значит:  
- Назначил `Ctrl + R` при английской раскладке
- При русской раскладке та же клавиша (где «К») **всё равно сработает**
- Точно как в играх — раскладка не имеет значения

## 8. Последние записи

Нижний блок (открывается по `↓`) показывает **6 последних аудиофайлов** из папки сохранения.

| Кнопка | Действие |
|---|---|
| `📎` | Вставить `![[файл.webm]]` в активную заметку |
| `▶` / `⏸` | Воспроизвести / поставить на паузу прямо в виджете |

Список автоматически обновляется после каждой новой записи.

## 9. CSS-сниппет для аудио в заметках

Файл `voice-notes.css` добавляет красивое оформление для аудио, вставленного в заметки через `![[файл.webm]]`:

- Плеер растягивается на всю ширину заметки (макс. 480px)
- Цвет акцента: тёмно-красный `#8f0000`
- Левая цветная полоса + тёмный фон для блока
- Иконка 🎙️ и имя файла над плеером

**Выглядит так в заметке:**
```
┌──────────────────────────────────┐
│ 🎙️ Голосовая 15-06-2026 14-30   │
│ ▓▓▓▓▓░░░░░░░░░░  0:42 / 1:15   │
└──────────────────────────────────┘
```

## 10. Настройки — подробно

Открываются кнопкой `⚙` в шапке виджета.

### Папка для сохранения

По умолчанию: `🗣 Голосовые`

Можно указать любой путь относительно корня хранилища:
- `Голосовые` — папка в корне
- `Журнал/Голос` — вложенная папка
- `🗣 Голосовые` — с эмодзи (работает)

Папка создаётся автоматически при первой записи, если её нет.

### Режим сохранения

Описан в [разделе 5](#5-режимы-сохранения).

### Горячие клавиши

Описаны в [разделе 7](#7-горячие-клавиши).

### Кнопка «Сохранить настройки»

Настройки сохраняются в `localStorage` браузера Obsidian.  
Это значит:
- Сохраняются между перезапусками Obsidian ✅
- Не переносятся на другой компьютер автоматически ❌  
  *(при переезде нужно перенастроить хоткеи вручную)*

## 11. Как работает под капотом

> Этот раздел — для тех, кто захочет разобраться или модифицировать виджет.

### Технологии

| Что | Технология |
|---|---|
| Отрисовка виджета | Чистый DOM (без фреймворков), создаётся через `document.createElement` |
| Запись звука | `navigator.mediaDevices.getUserMedia` + `MediaRecorder API` |
| Визуализация | `Web Audio API` — `AnalyserNode` с FFT-размером 64 бара |
| Транскрипция | `Web Speech API` (`SpeechRecognition`), язык `ru-RU` |
| Сохранение файла | `app.vault.createBinary()` — нативный Obsidian API |
| Вставка в заметку | `app.workspace.getMostRecentLeaf().view.editor.replaceSelection()` |
| Хранение настроек | `localStorage` браузера (ключ: `vr-cfg-v7`) |
| Хранение позиции | `localStorage` (ключ: `vr-pos-v7`) |
| Хоткеи | `document.addEventListener("keydown", ..., true)` — захват на уровне документа |
| Независимость от раскладки | `e.code` (физический код клавиши) вместо `e.key` |

### Имя файла при сохранении

```
Голосовая ДД-ММ-ГГГГ ЧЧ-ММ.webm
```

Пример: `Голосовая 15-06-2026 14-30.webm`

### Структура файла

```
🎙️ Голосовой Рекордер.md
├── YAML frontmatter  (cssclasses: [voice-recorder])
└── ```dataviewjs блок
    ├── Константы и конфиг
    ├── CSS (инжектируется в <head>)
    ├── HTML (добавляется в document.body как position:fixed)
    ├── Drag-логика
    ├── Expand/Collapse
    ├── Настройки + захват хоткеев
    ├── Глобальный keydown-обработчик
    ├── Canvas (Web Audio визуализация)
    ├── MediaRecorder (запись)
    ├── SpeechRecognition (транскрипция)
    └── Список последних файлов
```

### Как виджет не ломает Obsidian при перерендере

При каждом открытии вкладки dataviewjs перезапускается. Виджет решает это так:

```javascript
// Удаляем старый DOM-элемент
document.getElementById(W_ID)?.remove();

// Удаляем старый keydown-слушатель (хранится на window)
if(window[HK_KEY]){
    document.removeEventListener("keydown", window[HK_KEY], true);
}
```

Это предотвращает накопление дублирующихся обработчиков.

## 12. Частые вопросы и проблемы

### ❓ Виджет не появляется после открытия файла

**Проверь:**
1. Плагин Dataview установлен и включён
2. В настройках Dataview включён пункт **Enable JavaScript Queries**
3. Попробуй закрыть и снова открыть файл рекордера

---

### ❓ Кнопка «Начать запись» не реагирует / статус «Нет доступа к микрофону»

**Причина:** Obsidian не получил разрешение на микрофон.

**Решение:**
1. Obsidian → Меню → Help → Toggle developer tools
2. Вкладка **Application** → **Site settings** (или **Frame**) → **Microphone**
3. Установи значение **Allow**
4. Перезапусти Obsidian

---

### ❓ Транскрипция не работает / пусто

**Возможные причины:**
- Нет подключения к интернету (Web Speech API использует сервера Google)
- Браузер не поддерживает `webkitSpeechRecognition` (редко, но бывает в старых версиях)
- Речь была слишком тихой или неразборчивой

Запись при этом всё равно сохраняется — транскрипция опциональная функция.

---

### ❓ Горячие клавиши не работают

**Проверь:**
1. Настройки сохранены кнопкой **«Сохранить настройки»** (иначе хоткеи теряются)
2. Фокус не находится в поле ввода (хоткеи отключаются когда пишешь текст)
3. Файл рекордера открыт хотя бы в одной вкладке (виджет должен быть в DOM)
4. Если переустанавливал виджет — переназначь хоткеи заново (старые данные в localStorage могут быть от старой версии)

---

### ❓ Виджет пропал с экрана (улетел за край)

Позиция хранится в localStorage. Чтобы сбросить:
1. Obsidian → Help → Toggle developer tools
2. Вкладка **Application** → **Local Storage** → найди ключ `vr-pos-v7`
3. Удали его → перезапусти рекордер

---

### ❓ Хочу сменить папку сохранения

1. Нажми `⚙` в шапке виджета
2. Измени поле «Папка для сохранения»
3. Нажми **«Сохранить настройки»**

Старые записи при этом остаются в старой папке. Новые пойдут в новую.

---

### ❓ Хочу изменить цвет акцента с тёмно-красного на другой

В файле `🎙️ Голосовой Рекордер.md` найди строку:
```javascript
a: "#8f0000", aH: "#b30000",
```
И замени оба значения на нужный цвет.

В файле `voice-notes.css` найди все вхождения `#8f0000` и замени их.

---

### ❓ Хочу изменить язык транскрипции

В файле виджета найди:
```javascript
recog.lang="ru-RU";
```
И замени на нужный код языка, например:
- `"en-US"` — американский английский
- `"uk-UA"` — украинский
- `"de-DE"` — немецкий

---

### ❓ Записи сохраняются, но при воспроизведении тишина

Это может произойти если запись была остановлена сразу (< 1 секунды). Минимальная длина записи не ограничена, но файл может оказаться пустым. Просто удали его и запиши заново.
