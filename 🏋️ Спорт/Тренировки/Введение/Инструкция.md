# 🏋️ Спортивная среда — Инструкция

Всё на **одном экране**: сегодняшняя тренировка → план недели → прогресс → статистика.

## Структура

```
🏋️ Спорт/
├── 📊 Дашборд.md     ← главный экран, открывай его
├── План недели.md    ← какой день чем занимаемся (меняется с дашборда)
├── Профиль.md        ← рост, вес тела, история веса (создаётся сама)
├── Программы/        ← программы: ЛФК, Силовая A/B, Кардио, Баскетбол
├── Тренировки/       ← сюда дашборд создаёт записи по дням
│   └── 2026-10-17 Силовая A.md
└── Тренировки/Введение/
    ├── Инструкция.md ← этот файл
    └── 📖 Установка.md
```

## Три слоя

1. **План.** Упражнения живут в папке `Программы/`, а расписание недели — в `План недели.md`.
   Настраивается **один раз**, дальше просто повторяешь неделю.
2. **Сегодня.** Главная карточка вверху: что по плану, список упражнений с галочками и полями «что сделал фактически».
   Рядом — отдельная карточка «Каждый день · спина» (ЛФК, ~8 мин).
3. **Прогресс.** Вес и повторы по каждому упражнению — по этим же полям «факт».

---

## Как пользоваться каждый день

1. Открой **📊 Дашборд**.
2. В блоке **«Сегодня»** нажимай **галочку** у выполненного упражнения — оно отметится и запишется в заметку дня.
3. Вписывай **факт**: вес (кг) и повторы. Без этого поля «Прогресс по упражнениям» пустой.
4. Пройди **ЛФК для спины** (вторая карточка) — это базовый ежедневный объём.
5. Заполни блок **«Как прошло?»** внизу карточки: длительность, интенсивность, энергия, самоощущение.
6. Нужна отдельная тренировка не по плану? Кнопки снизу:
   - **＋ Тренировка** — выбираешь любую программу
   - **🧘 ЛФК**, **🏃 Кардио**, **🏀 Баскетбол** — создают тренировку на сегодня
   Всё открывается **карточкой заполнения прямо на дашборде** и прокручивает к ней —
   в пустую заметку больше не уводят. Сама заметка дня — просто журнал (кнопка «Открыть» в карточке).
7. Если чего-то не хватает — в карточке **«＋ упражнение»**: добавишь своё на ходу.

## Как прошло? (энергия и самоощущение)

Внизу каждой карточки тренировки — блок оценки самочувствия:

| Поле | Шкала | Зачем |
|------|-------|-------|
| ⏱ Длительность | минуты (поле ввода) | видно в истории тренировок |
| 🔥 Интенсивность | чипы 1–10 | высота столбиков в статистике за 7 дней |
| ⚡ Энергия | чипы 1–5 | как чувствуешь себя после/во время |
| 🙂 Самоощущение | чипы 1–5 | общая оценка дня тренировки |

Клик по чипу — оценка (повторный клик — сброс). Всё сохраняется само, появляется в «Последние тренировки».

## Профиль (рост, вес тела)

Секция **«Профиль»** на дашборде (между планом и прогрессом):

- впиши **рост** и **вес тела** → **Сохранить** (Enter тоже работает);
- при каждом сохранении веса добавляется запись в историю — **одна запись в день**;
- видны **ИМТ**, изменение к прошлой записи (▲/▼) и столбики истории веса.

Заметка `Профиль.md` создастся сама при первом сохранении. Это вес **тела**, не снарядов —
вес снарядов живет в полях «факт» каждого упражнения.

## План недели

- **Клик по дню** → выбираешь программу, **«Отдых»** или **«Убрать из плана»**.
- Сегодняшний день подсвечен красной рамкой.
- Менять план можно и прямо в заметке `План недели.md` (только не трогай `log: план`).

## Прогресс

Тянет из поля `fact_weight`/`fact_reps` в заметках тренировок:

- **последний результат** — вес × повторы;
- **PR** — лучший вес по этому упражнению;
- **столбики** — история последних 8 замеров (наведи — увидишь дату).

## Статистика

Всего / этот месяц / эта неделя / серия 🔥, плюс столбики по последним 7 дням.

- **Всего / месяц / неделя** считают только «настоящие» тренировки — **без ЛФК**.
- **Серия 🔥** учитывает **и ЛФК тоже**: сделал зарядку для спины — день зачтён.
  Это и есть смысл — держать ежедневную привычку.
- **Столбики за 7 дней** показывают любой активный день — включая дни, где была **только ЛФК**
  (столбик минимальной высоты). Высота столбика берётся из поля `intensity` — ставится чипом 🔥 в блоке «Как прошло?».

## Поля в frontmatter

### Тренировка (`Тренировки/`)

| Поле | Что означает | Пример |
|------|--------------|--------|
| `log` | **Обязательно.** Дашборд ищет записи именно по нему | `спорт` |
| `date` | Дата | `2026-10-17` |
| `program` | Программа, из которой создана | `Силовая A` |
| `type` | Тип для статистики | `Силовая` |
| `duration` | Минуты тренировки (поле в блоке «Как прошло?») | `60` |
| `intensity` | Интенсивность 1–10 (чипы в карточке) | `8` |
| `energy` / `mood` | Энергия и самоощущение 1–5 (чипы в карточке) | `4` |
| `готово` | true, когда отмечены все упражнения | `true` |
| `exercises` | Список упражнений с результатом | см. ниже |

```yaml
exercises:
  - name: Жим лёжа
    sets: 3
    reps: 10
    weight: 40        # план
    rest: 90
    done: true
    fact_weight: 40   # факт
    fact_reps: 10     # факт
```

### Программа (`Программы/`)

```yaml
log: программа
название: Силовая A
тип: Силовая
иконка: 💪
длительность: 60
exercises:
  - { name: Жим лёжа, sets: 3, reps: 10, weight: 0, rest: 90 }
```

### План недели

```yaml
log: план
пн: Силовая A
вт: Отдых
```

## Как добавить свою программу

1. Создай заметку в `🏋️ Спорт/Программы/`, например `📝 Йога.md`.
2. Во frontmatter: `log: программа`, `название`, `тип`, `иконка`, `длительность`.
3. Добавь `exercises` — список упражнений (`name`, `sets`, `reps`, `weight`, `rest`).
4. Готово: программа сразу появится в блоке «План недели» и в кнопке «＋ Тренировка».

Типы (для статистики): `Силовая`, `Кардио`, `ЛФК`, `Игра`, `Растяжка`, `HIIT`… придумай свои.

## Требования

## Советы

- **Заполняй «факт»** — это единственное, из чего потом строится прогресс.
- Рядом с дашбордом не открывай заметку-тренировку в тот же момент: правки в заметке
  и через дашборд не переписывают друг друга, а счётчик может показать старое значение
  до перезагрузки заметки.
- Нажми **Открыть** в карточке — перейдёшь в заметку дня и допишешь текстом, что хотел.
