# 🏋️ Спортивная среда — Инструкция

## Структура папок

```
🏋️ Спорт/
├── 📊 Дашборд.md          ← главный экран со статистикой
├── Шаблоны/               ← шаблоны тренировок (уже есть: Силовая, Руки, Кардио)
├── Тренировки/            ← сюда дашборд сохраняет новые тренировки
│   └── 2026-05-10 Пример.md
└── Введение/             ← инструкции (этот файл и 📖 Установка)
```

---

## Быстрый старт

1. Открой **📊 Дашборд.md** — это твой главный экран
2. Новая тренировка:
   - Нажми **«＋ Создать тренировку»** → выбери шаблон → файл создастся сам с сегодняшней датой
   - Или создай файл в `Тренировки/` вручную (см. поля ниже)

---

## Поля в frontmatter

| Поле        | Что означает                                      | Пример       |
|-------------|---------------------------------------------------|--------------|
| `log`       | **Обязательно!** Идентификатор для дашборда       | `спорт`      |
| `date`      | Дата тренировки                                   | `2026-05-10` |
| `type`      | Тип тренировки                                    | `Силовая`    |
| `duration`  | Длительность в минутах                            | `60`         |
| `intensity` | Интенсивность 1–10 (кликай по шкале)             | `8`          |
| `energy`    | Уровень энергии 1–10 (кликай по шкале)           | `7`          |
| `mood`      | Настроение 1–10 (кликай по шкале)                | `9`          |
| `notes`     | Краткая заметка                                   | `"Рекорд!"`  |

> ⚠️ Поле `log: спорт` обязательно в каждой тренировке — дашборд ищет записи именно по нему.

Если создаёшь шаблон — в поле `date` напиши `TPL_DATE_ISO`, в заголовке `TPL_DATE`. Дашборд сам подставит сегодняшнюю дату.

## Советы

- Открывай **Дашборд** в боковой панели, чтобы он всегда был виден
- Пополняй папку `Тренировки/` после каждой сессии
- Серия (streak) считается автоматически по consecutive дням
