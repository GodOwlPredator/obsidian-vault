# 📖 Установка и настройка спортивной среды

## Шаг 1 — Включи DataviewJS

**Настройки → Dataview → включи «Enable DataviewJS»**

Без этого дашборд не работает. Сниппет `sport-folders` (красные кнопки у папок) — отдельно,
для дашборда он не нужен.

---

## Шаг 2 — Где что лежит

```
[твой vault]/
├── .obsidian/snippets/sport-folders.css   ← красные кнопки «+» в списке файлов
└── 🏋️ Спорт/
    ├── 📊 Дашборд.md        ← открывай каждый день
    ├── План недели.md       ← расписание недели
    ├── Программы/           ← ЛФК · Спина, Силовая A/B, Кардио, Баскетбол
    └── Тренировки/          ← файлы тренировок (создаются из дашборда)
        └── Введение/        ← этот файл и Инструкция
```

---

## Как пользоваться

1. Открой **📊 Дашборд**.
2. Вверху — блок **«Сегодня»**: отмечай галочками и вписывай **факт** (вес, повторы).
3. Ниже — **«Каждый день · спина»**: ЛФК, галочки туда же.
4. **«План недели»**: клик по дню → выбери программу или «Отдых» (делается один раз).
5. **«＋ Тренировка»** — для внеплановой сессии: выбираешь программу, файл создаётся сам.

Файл создаётся по шаблону `Тренировки/ГГГГ-ММ-ДД Название.md`.

---

## Как добавить свою программу

1. Создай файл в папке `🏋️ Спорт/Программы/`, например `📝 Йога.md`.
2. Frontmatter:

```yaml
log: программа
название: Йога
тип: Растяжка
иконка: 🧘
длительность: 40
exercises:
  - { name: Приветствие солнцу, sets: 3, reps: 10, weight: 0, rest: 60 }
```

3. Программа сразу появится в выборе плана недели и в кнопке «＋ Тренировка».

Без `log: программа` заметка не будет считаться программой.

## Если папки называются иначе

Открой `📊 Дашборд.md`, в самом начале блока есть константы:

```js
const DIR           = "🏋️ Спорт";
const PROGRAMS_DIR  = DIR + "/Программы";
const TRAININGS_DIR = DIR + "/Тренировки";
const PLAN_PATH     = DIR + "/План недели.md";
const DAILY_PROGRAM = "ЛФК · Спина";
```

Поправь пути под свой vault. Пути намеренно вынесены наверх — менять их нужно только здесь.

---

## Пустой дашборд?

- **В «Сегодня» написано «Отдых»** → на этот день ничего не запланировано: кликни по дню в «План недели» (или оставь отдых).
- **«Прогресс» пустой** → ни в одной тренировке не заполнено поле `fact_weight`.
- **Странные тренировки в статистике** → найди в `Тренировки/` файлы с `date: TPL_DATE_ISO`
  и удали их: это старые шаблоны, они больше не нужны.
