# 📖 Установка и настройка спортивной среды

## Шаг 1 — CSS-сниппет (красные кнопки)

Уже установлен и включён: `.obsidian/snippets/sport-folders.css`.

Проверка: **Настройки → Оформление → CSS-сниппеты** → `sport-folders` включён ✅

---

## Шаг 2 — Включи DataviewJS

**Настройки → Dataview → включи «Enable DataviewJS»**

Без этого дашборд не работает.

---

## Шаг 3 — Где что лежит

```
[твой vault]/
├── .obsidian/snippets/sport-folders.css
└── 🏋️ Спорт/
    ├── 📊 Дашборд.md       ← открывай каждый день
    ├── Шаблоны/
    │   ├── 📝 Силовая.md
    │   ├── 📝 Руки.md
    │   └── 📝 Кардио.md
    └── Тренировки/          ← файлы тренировок (создаются из шаблонов)
```

---

## Как пользоваться

1. Открой **📊 Дашборд.md**
2. Нажми кнопку **«＋ Создать тренировку»**
3. Выбери шаблон из списка → файл создастся с сегодняшней датой
4. Или вкладка **«Новый комплекс»** → введи название → готово

---

## Как добавить свой шаблон

1. Создай файл в папке `🏋️ Спорт/Шаблоны/`, например `📝 Йога.md`
2. В frontmatter напиши `date: TPL_DATE_ISO` — дата подставится автоматически
3. В заголовке используй `TPL_DATE` — подставится как `ДД.ММ.ГГГГ`
4. Готово — файл сразу появится в окне создания на дашборде

---

## Как удалить шаблон

Просто удали файл из папки `🏋️ Спорт/Шаблоны/` — он исчезнет из списка.

---

## Если папки называются иначе

Открой `📊 Дашборд.md`, найди в самом начале:

```js
const CFG = {
    templatesDir: "🏋️ Спорт/Шаблоны",
    trainingsDir: "🏋️ Спорт/Тренировки",
};
```

И поправь пути под свой vault.

[[🏋️ Спорт/📊 Дашборд|← Дашборд]]
