# Домашний ИИ-помощник с напоминаниями

```dataviewjs
/* ═══ Карточка записи «Идея» ═══ */
let DIR = dv.current().file.folder, SRC = null, err = null;
while (DIR) {
    try { SRC = await app.vault.adapter.read(DIR + "/⚙️ движок.js"); break; } catch (e) { err = e; }
    const i = DIR.lastIndexOf("/"); DIR = i < 0 ? null : DIR.slice(0, i);
}
if (!SRC) { dv.paragraph("⚠️ Не найден движок раздела «Электроника». Ошибка: " + (err && err.message || "")); }
else {
    const elMain = new Function("dv", "app", SRC + "\nreturn elMain;")();
    await elMain(dv, app, "card");
}
```

## 💭 Зачем это нужно

Хочется, чтобы устройство, которое я сам собрал, помогало удерживать режим, а не отвлекало.
Пример желаемого напоминания: «Абдул, ты уже полтора часа в Instagram и листаешь Reels,
у тебя есть незаконченные дела, что случилось?»

Это одновременно и электронный проект, и решение моей реальной проблемы: Reels и игры
подменяют учёбу, а силы воли мало — нужны инструменты. И главное: авторство. Приятно
пользоваться вещью, которую сам придумал и сделал.

## 🔩 Как можно реализовать

- База: Raspberry Pi или старый ноутбук — на нём локальная модель (не облако, чтобы не
  светить свои данные).
- Голос: микрофон + динамик. Начать с простого: он говорит → программа распознаёт команду.
- Данные о времени в приложениях: свой скрипт на ПК пишет статистику запущенных окон
  (похоже на то, что уже делает activity-tracker).
- Умный дом: розетки/реле на ESP32 — включать свет, выключать монитор, таймер на игры.
- Шаг первый, самый маленький: программа, которая раз в 30 минут читает вслух,
  сколько времени прошло в приложении, и спрашивает «продолжаем?»

## ⚠️ Сложности и вопросы

- Начинать нужно с малого. Пугает начало большой задачи, когда непонятно с чего начать.
- Голосовое распознавание локально — нетривиально; можно упростить до нажатия кнопки.
- Не должно превратиться в «настраиваю систему вместо учёбы» — риск, который я знаю.
- Пайка и электричество: техника безопасности обязательна (см. 🛠 Техника безопасности).
