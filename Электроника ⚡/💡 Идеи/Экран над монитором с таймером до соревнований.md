# Экран над монитором с таймером до соревнований

```dataviewjs
/* ═══ Карточка записи «Идея» ═══ */
let DIR = dv.current().file.folder, SRC = null, err = null;
while (DIR) {
    try { SRC = await app.vault.adapter.read(DIR + "/⚙️ движок.js"); break; } catch (e) { err = e; }
```

## 💭 Зачем это нужно

Утренние соревнования по электроннике в колледже: всегда непонятно, сколько осталось до начала.
Экран над монитором показывает это краем глаза, не отрываясь от работы. Голосовое включение —
чтобы руки были свободны (часто в руках паяльник или детали).

Дополнительный плюс: экран становится «часами мастерской» — температура, таймер пайки,
сколько времени до конца пары.

## 🔩 Как можно реализовать

- Микроконтроллер: ESP32 (уже есть в складе) — есть и Wi-Fi, и микрофон.
- Матрица светодиодов 8×32 или 16×32 на WS2812B — ярко, дёшево, легко подключать.
- Голосовое включение: локальное распознавание (не облако, чтобы работало без интернета).
  Начать проще: кнопка + резерв на голос.
- Часы: NTP по Wi-Fi, держать время между перезагрузками.
- Корпус: печатать самому в 3D — своя же модель, как в 3D-вики.

## ⚠️ Сложности и вопросы

- Питание матрицы: яркий свет = ток. Нужен отдельный блок питания 5 В, не тянуть от USB ноутбука.
- Распознавание голоса на ESP32 — тяжело. Может, нужен отдельный модуль или Raspberry Pi.
- Крепление над монитором: чтобы не падало и не мешало. Корпус проще всего сделать в 3D.
- Шум/яркость вечером: нужен диммер по времени суток.

## 🎨 Референсы

- Матрицы на WS2812B: примеры проектов на YouTube по запросу «LED matrix ESP32».
- Даташит ESP32-WROOM.

## 📝 Заметки

- Начать с минимума: одна матрица 8×8, кнопка, счётчик до времени. Голос добавлять последним.
