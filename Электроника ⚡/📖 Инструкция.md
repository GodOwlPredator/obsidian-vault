# 📘 Электроника — Инструкция

## Что это

Личная мастерская-конструкторская: идеи устройств, проекты, готовые работы, склад деталей,
инструменты, конспекты и полезные ресурсы. Всё связано между собой через **проекты** —
как в [[3D 🧊/3D wiki/🏠 Главная|3D-вики]], только под железо.

Открой **[[🏠 Главная]]** — это хаб со всеми записями, поиском и кнопками добавления.

## Быстрый старт

1. Открой **🏠 Главная.md**.
2. Нажми нужную кнопку: **＋ Идея**, **＋ Проект**, **＋ Готовая работа**, **＋ Компонент**,
   **＋ Инструмент**, **＋ Конспект** или **＋ Ресурс**.
3. Заполни название (и пару полей) → **Создать**. Файл создаётся из шаблона, поле `log`
   подставляется автоматически, метка `шаблон` снимается, заметка сразу открывается.
4. Переключатели сверху: **🧩 Склад**, **🛠 Техника безопасности**, **⚙️ Центр**, **📘 Инструкция**.

> Шаблоны помечены полем `шаблон: true`. Благодаря метке они не попадают в статистику
> и списки. Создавай записи кнопками — тогда метка снимается сама.

## Как вести проект

**Проект** — главная сущность раздела. Он собирает вокруг себя идеи, компоненты, конспекты,
ресурсы и готовые работы.

1. Создай проект кнопкой **＋ Проект**.
2. В любой другой записи укажи поле `проект: «Название проекта»` — прямо при создании в модалке
   или прямо в заметке.
3. Открой карточку проекта — внизу появятся **связанные записи** и **граф связей**.
   Клик по узлу открывает запись.
4. В теле проекта есть чеклист этапов — галочки прямо в карточке проекта:
   компоненты → схема → макет → пайка → прошивка → тест.

## Склад компонентов

Отдельная страница **🧩 Склад.md**: все детали одной таблицей.

- **−** и **+** прямо в строке — остаток сразу сохраняется в заметку компонента.
- Строка подсветится жёлтым, если `количество` равно нулю или не больше `минимум`.
- Чипы сверху фильтруют по типу (резистор, конденсатор, МК, датчик…), поиск ищет и по значению,
  и по корпусу, и по месту хранения.
- Кнопка **⚠️ Только мало** показывает то, что пора докупить.

В карточке компонента удобно держать ссылку на даташит, на магазин и точное место
(«ящик 2, коробка R/C») — так деталь находится за пять секунд.

## Чего раздел не делает

- Не считает стоимость проекта автоматически — суммы пишутся вручную в поле `бюджет`
  или `стоимость`.
- Не подтягивает даташиты и цены из интернета — только ссылки, которые ты добавил.
- Не связан с симуляторами схем. Если будешь рисовать в KiCad — добавляй папку проекта
  рядом и ссылку полем `ссылка`.

## ⚙️ Техническая часть

Весь код страниц раздела лежит в **одном файле** `⚙️ движок.js`. Каждая заметка подключает
его коротким блоком:

```js
const SRC = await app.vault.adapter.read("Электроника ⚡/⚙️ движок.js");
const elMain = new Function("dv", "app", SRC + "\nreturn elMain;")();
await elMain(dv, app, "hub");   // "hub" | "stock" | "card"
```

Стили — в сниппете `.obsidian/snippets/electronics.css`. Если сниппет выключен, движок сам
подключает файл при загрузке страницы, так что раздел работает в любом случае.

Изменения в `⚙️ движок.js` подхватываются при следующем рендере заметки — перезапускать
Obsidian не нужно.

> ⚠️ Если переименовать `⚙️ движок.js` или папку `Электроника ⚡`, страницы перестанут
> загружаться и покажут предупреждение. В таком случае поправь путь в блоке каждой заметки
> (он одинаковый во всех) или верни старое имя.
